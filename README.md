# Calculator (HTML, CSS, JS)

A simple calculator built with **HTML**, **CSS**, and **JavaScript**, featuring **Light Mode** and **Dark Mode** support.

🔗 **Live Demo:** https://hawrehsensei89.github.io/calculator-html-css-js/
📦 **Repository:** https://github.com/HawrehSensei89/calculator-html-css-js

## ✨ Features

- Basic calculator operations (addition, subtraction, multiplication, division)
- Light / Dark mode toggle
- Clean and responsive UI
- Built with pure HTML, CSS, and JavaScript (no frameworks)

## 🗂 Project Structure

```
calculator-html-css-js/
├── assets/
│   └── fonts/       # Custom fonts used in the UI
├── css/              # Stylesheets
├── js/               # JavaScript logic
└── index.html        # Main entry point
```

## 🚀 Getting Started

To run this project locally:

1. Clone the repository
   ```bash
   git clone https://github.com/HawrehSensei89/calculator-html-css-js.git
   ```
2. Navigate into the project folder
   ```bash
   cd calculator-html-css-js
   ```
3. Open `index.html` in your browser

No build tools or dependencies required — it's a static site.

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
